# «Сигнал» — кабинет, в котором деканат пишет первым

Вымышленный вуз: Университет «Горизонт». Продукт: «Сигнал». Логотип — собственный простой SVG (сигнальная точка с волной).

Идея: студент открывает кабинет и сразу видит, что важно сегодня. Кабинет сам выводит это из его данных и объясняет, почему показал.

Делай строго по этапам. После каждого этапа версия должна быть рабочей и пригодной к подаче.

## Seed (только при пустой базе, все даты относительно дня запуска)
- Расписание — недельный шаблон на обе группы, 3–4 пары в день, пн–пт, 6 дисциплин на группу, вымышленные преподаватели, аудитории 101–415.
- Мария: средний высокий балл, допуск по всем дисциплинам; справка об обучении «Готова», справка для визы «В работе»; дедлайн через 4 дня; завтра смена аудитории.
- Тимур: «Корпоративные финансы» 18 баллов при пороге 25; курсовая через 2 дня; заявка «Справка для военкомата» в статусе «Подана»; сегодня перенос пары 10:30 → 13:50; послезавтра отмена пары.
- Экзамены: первый через 19 дней, дальше через 22, 25, 28.
- 3 объявления (одно важное), по 2–3 непрочитанных уведомления у каждого студента.

## Этап 1. Обязательное ядро
Нижняя панель: Сегодня · Расписание · Учёба · Заявки · Ещё. В шапке колокольчик со счётчиком.

1. **Профиль** («Ещё»): ФИО, факультет, направление, курс, группа; выход.
2. **Расписание**: вкладки «День» и «Неделя»; время, дисциплина, преподаватель, аудитория. Изменения заметны: старое зачёркнуто, новое жирным, бейдж «Перенос», «Отмена» или «Другая аудитория». Блок «Изменения на этой неделе».
3. **Учёба**: общая картина одной строкой («Допуск: 5 из 6, 1 под риском»), список дисциплин со светофором (зелёный / жёлтый / красный), баллы и порог, зачёты; блок «Сессия» с датами экзаменов.
4. **Заявки**: «Заказать» в два шага (тип: справка об обучении, справка для военкомата, справка для визы, заявление на пересдачу; затем комментарий и подтверждение). Список «Мои заявки» с линией статуса Подана → В работе → Готова и датами. Страница заявки `/requests/<id>` — только своя.
5. **Уведомления**: лента (объявления деканата, изменения расписания, дедлайны, заявки), отметка «прочитано», кнопка «Прочитать все».
6. **Сегодня (простая версия)**: ближайшая пара, ближайший дедлайн, последняя заявка со статусом.
7. **Сотрудник** `/staff`: очередь заявок, кнопки «В работу» и «Готова» (студент получает уведомление); форма «Перенести или отменить пару» (группа получает уведомление); форма «Объявление».

Проверка этапа: Тимур входит → видит перенос → видит оценки и сессию → заказывает справку → сотрудник переводит её в «В работе», затем «Готова» → Тимур видит уведомление. Мария по адресу заявки Тимура получает 404. Студент на `/staff` получает 403. На ширине 360 px нет горизонтальной прокрутки.

## Этап 2. «Деканат пишет первым»
Экран «Сегодня» показывает до 5 карточек. Они вычисляются при открытии страницы, без фоновых задач.

| Правило | Условие | Пример текста | Кнопка |
|---|---|---|---|
| Перенос или отмена | Изменение пары на сегодня или завтра | «Сегодня «Макроэкономику» перенесли: 10:30 → 13:50, ауд. 412» | «Открыть расписание» |
| Дедлайн | Срок через 3 дня или раньше, не сдано | «До курсовой 2 дня» | «Отметить сданным» |
| Риск | Баллов меньше порога допуска | «По «Корп. финансам» 18 из 25 нужных. Не хватает 7» | «Что нужно для допуска» |
| Заявка | Статус изменился с прошлого входа | «Справка готова, кабинет 214» | «Открыть заявку» |
| Сессия | До первого экзамена 21 день или меньше | «Сессия через 19 дней. Допуск: 5 из 6» | «План сессии» |
| Объявление | Важное, для группы | заголовок объявления | «Подробнее» |

У каждой карточки:
- строка «Почему я это вижу» (раскрывается, человеческим языком называет данные и правило);
- кнопка действия в одно касание;
- «Понятно» — скрывает карточку (ключ = правило + id объекта).

Сверху блок «Пока вас не было: N изменений» (по `last_seen_at`). Если карточек нет — «Всё спокойно. Ближайшая пара …».

## Этап 3. Только если этапы 0–2 выкачены и проверены
1. «Машина времени» для жюри: переключатель «Демо-время: сегодня / +1 / +3 / +7 дней» (хранится в сессии, меняет `now()`), заметный баннер «Вы смотрите кабинет через N дней. Вернуться».
2. Счётчик «Вопросов решено без похода в деканат: N» (готовые заявки и ответы).
3. Кнопка сотрудника «Сбросить демо-данные».
