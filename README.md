# Цифровой деканат

Демонстрационный кабинет студента и сотрудника деканата для номинации «Вайб-кодинг» MGIMO AI Challenge 2026. Все данные вымышлены. Это учебный прототип.

[Открыть сайт](https://traderonbb-sketch123.github.io/signal-dekanat/)


## Как попробовать

На главной нажмите «Перейти ко входу» и выберите одну из трёх демо-ролей. Студент видит ближайшую пару, переносы и свои заявки. Откройте сайт во второй вкладке того же браузера и войдите сотрудником деканата. Когда сотрудник отметит заявку готовой, студент увидит новый статус в своей вкладке.

Разметка, стили, графика и логика находятся в `index.html`. Его можно открыть локально. Демо хранит изменения в браузере. Для внешних шрифтов предусмотрена системная замена.
