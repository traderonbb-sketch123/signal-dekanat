# Правила проекта «Цифровой Деканат»

Конкурсный прототип личного кабинета студента (MGIMO AI Challenge 2026, «Вайб-кодинг»). Полное задание — в `SPEC.md`. Дедлайн жёсткий: делай просто и надёжно.

## Стек (не менять)
- Python 3.12, Flask, Flask-SQLAlchemy, Flask-WTF (CSRFProtect), gunicorn. Других зависимостей не добавлять без крайней нужды.
- Серверные шаблоны Jinja, один файл CSS, минимум обычного JS. Без сборки фронтенда, без внешних CDN, шрифты системные, иконки — эмодзи или свои SVG.
- База: адрес из `DATABASE_URL`, по умолчанию `sqlite:////data/app.db`; если `/data` недоступна для записи — `sqlite:///instance/app.db`.
- `SECRET_KEY` только из окружения (локально — случайный при старте). Никаких ключей и паролей в коде, кроме демо-аккаунтов в seed и README.
- `Dockerfile`: gunicorn, 2 воркера, порт из `PORT` (по умолчанию 80). Маршрут `/health` отдаёт `ok`.

## Обязательные правила
1. Студент определяется только по сессии. Любая выборка личных данных фильтруется по `student_id` текущего пользователя; чужой id в адресе → 404. Страницы сотрудника — только роль `staff`, иначе 403.
2. Пароли — только `werkzeug.security.generate_password_hash`.
3. Все формы — POST с CSRF-токеном. Cookie сессии: HttpOnly, SameSite=Lax, Secure в продакшене.
4. Mobile-first: всё работает на ширине 360 px без горизонтальной прокрутки. Нижняя панель из 5 вкладок.
5. На каждой странице плашка: «Концепт для конкурса MGIMO AI Challenge 2026. Не официальный сервис вуза. Все данные вымышлены».
6. Только вымышленные данные. Никаких логотипов и названий настоящих вузов.
7. У каждого списка есть пустое состояние с подсказкой, у каждой формы — понятные ошибки по-русски.
8. Текущее время брать только из одной функции `now()` в `app/clock.py`.
9. Seed выполняется только при пустой базе. Данные пользователей сохраняются между перезапусками.
10. Не переписывай работающее. После каждого этапа: запусти приложение, проверь вручную сценарий этапа, сделай git commit.

## Журнал для конкурса (обязательно)
После каждого этапа дописывай в `docs/ai-log.md`: номер этапа, дословный промпт, что получилось, какая была ошибка ИИ, как исправлена. Это пойдёт в описание работы для жюри, пиши честно и коротко.
